# Безопасный промпт http://fintrackdeploy.github.io/ProntManager/

Веб-приложение для педагогов и учащихся: проверяет запрос к генеративному ИИ до отправки, находит персональные данные и лишние подробности по восьми критериям методики (C1–C8), объясняет риск и предлагает шаблонную безопасную редакцию. Есть тренажёр на синтетических кейсах и печать отчёта.

**Приватность:** всё работает в браузере. Приложение не отправляет текст по сети, не использует localStorage, cookies и аналитику. Строгая политика CSP, тест `npm test` проверяет, что в коде нет сетевых и storage-API.

## Возможности
Проверка по критериям C1–C8, подсветка и объяснения, безопасная редакция (копирование, .txt, печать), загрузка .txt/.docx локально, тренажёр из 12 кейсов с режимом «перепишите сами», методика занятия, страницы приватности, PWA-офлайн.

## Нейросеть
Для имён, организаций и мест используется **Slovnet NER** из проекта Natasha (MIT): эмбеддинги Navec + формы слов → три свёрточных слоя → CRF. Модель обучена на новостных текстах. Вывод перенесён на JavaScript (`assets/ner.js`) и работает на устройстве без сети; веса (~14 МБ, словарь Navec сокращён до 100 000 слов) лежат в `assets/ner/ner-data.js` и загружаются один раз. Пересборка весов: `pip install natasha`, затем `python tools/export_ner.py`.
Правила и нейросеть дополняют друг друга: нейросеть находит имена вне словаря, правила закрывают телефоны, документы, секреты и контекст. Поверх модели стоят фильтры от типичных ошибок (слово-команда в начале запроса, одиночные «имена» без признаков фамилии).

## Быстрый старт
- Локально: откройте `index.html` в браузере (офлайн-режим PWA включается при размещении по http/https).
- Сервер для разработки: `npm start` (нужен Node 18+).
- Тесты и метрики: `npm test`.

## Структура
`index.html`, `privacy.html`, `404.html`, `assets/` (включая `tokens.css`, шрифты и `vendor/jszip`) (стили, анализатор `analyzer.js`, интерфейс `app.js`), `sw.js` и `manifest.webmanifest` (PWA), `tests/` (набор из 40 промптов и скрипт метрик), `deploy/` (nginx), `Dockerfile`, `docker-compose.yml`, `_headers`, `.github/workflows/pages.yml`.

## Деплой
1. **GitHub Pages:** загрузите проект в репозиторий, в Settings → Pages выберите источник «GitHub Actions». Workflow запускает тесты и публикует сайт.
2. **Netlify / Cloudflare Pages:** публикуйте корень проекта как статику, заголовки безопасности берутся из `_headers`.
3. **Docker:** `docker compose up -d --build`, сайт на `http://localhost:8080`. Для HTTPS поставьте перед контейнером reverse proxy (Caddy, Traefik, nginx с сертификатом).
4. **Свой nginx:** скопируйте файлы в корень сайта и используйте `deploy/nginx.conf`.

При изменении файлов приложения увеличивайте версию `V` в `sw.js`, иначе браузеры будут отдавать старый кэш.

## Ограничения версии 1.0
- Нейросеть распознаёт только имена, организации и места и хуже работает на разговорных текстах, опечатках и редких именах. Косвенная идентификация без явных маркеров не находится.
- Метрики `npm test` (44 вымышленных промпта) получены на тех же примерах, на которых дорабатывались правила и фильтры. Независимой оценки пока нет. Перенос нейросети на JS сверен с Natasha: совпали 32 из 32 эталонных сущностей, 6 лишних.
- Нормативная сверка не проведена; форматы белорусских документов требуют проверки.
- Результат не является гарантией безопасности и юридическим заключением.

## Дорожная карта

1. Заполните оператора в `privacy.html` и подвале `index.html`.
2. Выберите и добавьте лицензию проекта (`LICENSE`). Шрифты (OFL) и JSZip идут со своими лицензиями.
3. Проведите нормативную сверку и проверьте форматы белорусских документов.
